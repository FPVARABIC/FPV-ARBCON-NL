# fiercon in beeld

De startpagina en firmwareselector zijn op de openbare website vastgelegd. De zeventien configuratieschermen hieronder gebruiken dezelfde schermcomponenten in een lokale browsersessie met testgegevens. De testbalk boven die beelden geeft dat aan. Klik op een afbeelding voor het oorspronkelijke formaat.
